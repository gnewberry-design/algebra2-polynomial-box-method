🔥 Warm-Up / Bell Ringer

Expand (x + 2)(x + 3). What four products belong in a 2 × 2 area model?

💡 Show warm-up answer

x², 3x, 2x, and 6. Combine like terms: x² + 5x + 6.

Dividend ÷ Divisor = Quotient
(Divisor × Quotient) + Remainder = Dividend

👩‍🏫 I Do – Direct Instruction (Learn)

Divide (x² + 5x + 6) ÷ (x + 2).

1️⃣ Set up the model. Put the divisor terms x and +2 down the left side. The unknown quotient terms go across the top.
2️⃣ Find the first top term. x² ÷ x = x. The first column contains x² and 2x.
3️⃣ Find what is left. We need 5x altogether. Since 2x is already in the box, 3x remains. So the next top term is +3.
4️⃣ Multiply to fill the boxes. x·3 = 3x; 2·3 = 6.

🧮 Add all four cells: x² + 3x + 2x + 6 = x² + 5x + 6.

✅ Quotient = x + 3; Remainder = 0

🤝 We Do – Guided Practice

Divide (x² + 7x + 12) ÷ (x + 3). Fill in the two quotient boxes and all four interior boxes. Type algebraic terms like x, 4x, x^2, 12. You can use a minus sign for negative terms.

💡 Guided hint

Start with x² ÷ x = x. Then subtract 3x from 7x to find the next product, 4x.

✏️ You Do – Independent Practice

Each problem has a complete 2 × 2 box just like WE DO. Fill in both quotient terms and all four products, then check your work. Each correctly completed box counts as one problem.

🧩 Differentiation / Accommodations

If below 80%: Work in a small group to revisit dividing leading terms, multiplying box entries, and combining like terms. Then retry the five problems.

If 80% or above: Extend to missing terms, negative coefficients, and remainders. Explain why divisor × quotient + remainder reproduces the dividend.

🌟 Optional Extension – Missing Terms & Remainders

Missing term: When dividing (x² + 0x − 9) by (x + 3), the zero coefficient reminds you there is no x term. The quotient is x − 3.

Remainder: (x² + 5x + 7) ÷ (x + 2) gives quotient x + 3 with remainder 1. Check: (x + 2)(x + 3) + 1 = x² + 5x + 7.

🔎 What does the remainder mean?

The rectangle accounts for x² + 5x + 6, with 1 left over. The complete result can be written x + 3 + 1/(x + 2).

🎟️ Closure & Exit Ticket

Divide (x² + 9x + 20) ÷ (x + 4) using the box. Complete all six entries, then check.

Reflection: How did the box help you decide what the quotient must be?

📊 Assessment / Evidence of Learning

Formative evidence: Student responses during warm-up and guided box practice; accuracy of box entries and explanations during independent practice.

Mastery check: Target at least 80% accuracy (teacher-selected threshold). Students below 80% receive targeted small-group reteaching followed by reassessment.

Exit-ticket evidence: Correct quotient, accurate box entries, and a multiplication check. Check performance by learning target, not only overall score.
